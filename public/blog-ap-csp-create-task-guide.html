AP CSP Create Performance Task: Requirements, Deadline and Tips

By Syed Shahmikh Ali · Published 15 September 2026 · Updated 15 September 2026

The AP CSP Create performance task is a program you design and build during the school year, and together with the written response on exam day it is worth 30% of your AP score. For 2027 the Create task must be submitted by 11:59 PM ET on 30 April, and the exam is on 14 May. You submit your program code, a short video of it running and a Personalized Project Reference that you use in the exam.

Key takeaways

  • Section II, the Create task plus written response, is worth 30% of the AP CSP score.
  • The 2027 submission deadline is 30 April at 11:59 PM ET; the exam is on 14 May 2027.
  • Your program needs input, output, a list, and a procedure with a parameter that uses sequencing, selection and iteration.
  • On exam day you answer written questions about your own code using your Personalized Project Reference.

What is the Create performance task?

AP Computer Science Principles is the broad, introductory AP computing course. College Board's course overview describes it as covering the breadth of the field. Its exam has two sections. According to the AP CSP exam page, Section I is 70 multiple-choice questions in 120 minutes, worth 70%, and Section II, worth 30%, combines the Create performance task with written-response questions on exam day.

The Create task is your chance to earn marks before you enter the exam room. You choose the topic and the programming language your class uses, and you get class time to work on it.

What do you have to submit?

ComponentWhat it is
Program codeThe complete code of your program, as a PDF
VideoA short screen recording, up to one minute, showing the program running with input and output
Personalized Project ReferenceScreenshots of specific code segments: your list being created and used, and your procedure and where it is called

The Personalized Project Reference, often shortened to PPR, must contain code only. It must not include comments or any text that explains the code, because you bring it into the exam. Check College Board's current student handout for the exact format rules, and submit through the AP Digital Portfolio before the deadline.

What must your program include?

  • Input from a user, a file or a device, which affects what the program does.
  • A list (or other collection) that stores several values and is actually used to manage complexity. A list you create but never need does not count.
  • A procedure you wrote with a name, a return type if needed, and at least one parameter that affects what it does.
  • An algorithm inside that procedure that includes sequencing, selection (an if statement) and iteration (a loop).
  • Calls to your procedure from elsewhere in the program.
  • Output that depends on the input and the program's logic.

Here is a small Python example of a procedure that meets the algorithm requirement:

def count_above(scores, limit):
    count = 0
    for s in scores:
        if s > limit:
            count = count + 1
    return count

It has a parameter that changes the result, a loop, an if statement and steps in order. Your own procedure should be this clear. Graders are not looking for complexity; they are looking for each required feature.

What makes a good Create task project?

Pick something small that naturally needs a list. Good choices include a quiz that stores questions and scores, a study planner that filters tasks by subject, a simple inventory or library tracker, a text-based adventure with an item list, or a tool that analyses a list of numbers such as temperatures or grades.

Avoid projects where the list is decoration. Ask yourself: if I removed the list, would I need dozens of separate variables instead? If yes, the list manages complexity. Also avoid anything so large that you cannot finish it in the class time available. A complete simple program scores better than an unfinished ambitious one.

How do you prepare for the written response?

On exam day you answer questions about your own program, with your PPR in front of you. The questions ask you to explain things such as what your program does, how your list manages complexity, how your procedure's algorithm works, what would happen with different inputs, and how you tested or would change the code.

  1. Practise explaining your procedure aloud, line by line, to a friend or teacher.
  2. Write down two calls to your procedure with different arguments that give different results, and what each returns.
  3. Be able to say what would break if your list were replaced with separate variables.
  4. Describe one error you found during development and how you fixed it.
  5. Use precise words: parameter, argument, iteration, condition, return value.

Answer the question asked, about your own code, in full sentences. Vague answers that could describe any program do not earn points.

What help are you allowed?

The Create task must be your own work. College Board allows collaboration with a partner on program development in some circumstances, but your video, PPR and written responses must be individual, and any code you did not write must be acknowledged. Rules on AI tools are set by College Board and your teacher, so read the current student handout carefully before using any assistant.

The safe way to use AI is for learning: ask it to explain a concept or an error message, not to write your project. See how to use ChatGPT study mode and do AI detectors work?. Keep your drafts and notes as evidence of your process.

How does the Create task affect your score?

Because Section II is 30% of the exam, a strong Create task and written response can lift a borderline multiple-choice performance by a full grade. College Board's AP CSP score distributions show how students performed each year. Try your own numbers in our AP Computer Science score calculator.

One note for younger students: College Board has said AP CSP is being redesigned for the 2027 to 2028 school year, so later exams may differ. If you are deciding which course to take, read AP Computer Science A vs Principles.

Frequently asked questions

When is the AP CSP Create task due in 2027?

The Create performance task must be submitted in the AP Digital Portfolio by 11:59 PM ET on 30 April 2027. The exam is on 14 May 2027.

How much is the Create task worth?

The Create performance task and the written response together make up Section II, which is worth 30% of the AP CSP exam score.

What programming language can I use for the Create task?

Any language your teacher allows that supports the required features. Many classes use Python, JavaScript or a block-based language.
