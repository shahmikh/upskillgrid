AZ-900 vs AWS Cloud Practitioner: Which Cloud Certification Should You Take First?

By Syed Shahmikh Ali · Published 11 November 2026 · Updated 11 November 2026

Pick AZ-900 if you want the quicker, slightly easier exam or you expect to work with Microsoft products, and pick AWS Cloud Practitioner if the jobs you want mention AWS. Both are beginner exams with a pass mark of 700 out of 1000 and a fee of about US$100. The biggest practical difference is that AZ-900 is 45 minutes and never expires, while the AWS exam is 90 minutes and lasts three years.

Key takeaways

  • AZ-900 is a 45-minute exam costing US$99, and the certification does not expire.
  • AWS Cloud Practitioner (CLF-C02) has 65 questions in 90 minutes, costs US$100 and is valid for three years.
  • Both need 700 out of 1000 to pass and have no prerequisites.
  • Neither is enough for a cloud job alone; they are a first step toward associate-level certifications.

What is the difference between AZ-900 and AWS Cloud Practitioner?

Both exams test the same idea: do you understand what cloud computing is, what the main services do, and how pricing, security and support work? AZ-900 asks this about Microsoft Azure. The AWS Certified Cloud Practitioner exam, code CLF-C02, asks it about Amazon Web Services.

The Azure figures come from Training Camp's Azure Fundamentals guide and the AWS figures from its AWS Cloud Practitioner guide. Fees vary by country, and Microsoft in particular prices exams by region.

What does AZ-900 cover?

AZ-900 has three areas: cloud concepts, Azure architecture and services, and Azure management and governance. You will meet ideas such as regions, virtual machines, storage accounts, Microsoft Entra ID and cost management. No coding or hands-on configuration is needed.

Because the certification never expires, AZ-900 is a low-risk first exam. Microsoft's free Microsoft Learn modules cover the whole syllabus, so many students pass it with no paid course.

What does AWS Cloud Practitioner cover?

CLF-C02 has four domains: cloud concepts, security and compliance, cloud technology and services, and billing, pricing and support. It asks about more individual services than AZ-900 does, including compute, storage, databases and networking, and it puts more weight on security and billing.

AWS suggests up to six months of exposure to AWS, but it is not required. The exam is multiple choice and multiple response.

Which exam is harder?

Most candidates find AZ-900 slightly easier. ExamCert's comparison gives the reasons: fewer questions, a shorter sitting, and question types such as drag-and-drop and yes or no that are quicker to answer than AWS's scenario questions.

The difference is small. With no experience, plan two to four weeks for AZ-900 and three to six weeks for Cloud Practitioner, at about an hour a day.

How do you prepare for free?

You can pass either exam without paying for a course. Both providers publish free official training that follows the exam outline, and both offer a free account tier so you can try the services.

  1. Read the official exam guide first and copy the domain list into your notes. It tells you exactly what can be asked.
  2. Work through the provider's free learning path: Microsoft Learn for AZ-900, or AWS Skill Builder's Cloud Practitioner Essentials for CLF-C02.
  3. Open a free account and click through the main services. Create a storage bucket or a small virtual machine, then delete it so you are not charged.
  4. Finish with timed practice questions and learn the shared responsibility model and pricing options thoroughly, since both exams return to them again and again.

A common mistake is memorising service names without knowing what problem each one solves. For every service, write one sentence that starts with 'You would use this when'. That habit also helps in interviews.

Which should you take first?

  • Take AZ-900 if your school, university or employer uses Microsoft 365, or you want a fast first pass that never needs renewing.
  • Take AWS Cloud Practitioner if local job adverts ask for AWS, or you plan to go on to AWS Solutions Architect Associate.
  • Do not take both straight away. The concepts overlap so much that your time is better spent on an associate-level exam next.

Frequently asked questions

Does AZ-900 expire?

No. Microsoft fundamentals certifications such as AZ-900 do not expire. The AWS Cloud Practitioner certification is valid for three years.

Can I get a job with AZ-900 or AWS Cloud Practitioner?

Rarely with that alone. Both prove basic knowledge. Employers usually look for an associate-level certification, hands-on projects or IT experience as well.

Is AZ-900 easier than AWS Cloud Practitioner?

Slightly, for most people. It is a shorter exam with fewer questions, and it covers fewer individual services.
