AP Computer Science A FRQ Guide: How to Score More on Free Response

By Syed Shahmikh Ali · Published 22 August 2026 · Updated 22 August 2026

The free-response section of AP Computer Science A has four questions in 1 hour 30 minutes and is worth 45% of your score. You write Java by hand, and graders award points for specific things your code does, not for perfection. To score well, know the four question types, attempt every part, use the methods the question gives you, and practise writing code on paper under timed conditions.

Key takeaways

  • Section II has 4 free-response questions in 90 minutes and counts for 45% of the exam.
  • Points are awarded for individual correct pieces of logic, so partial answers still score.
  • Each question targets a skill: methods and control structures, class design, ArrayList, and 2D arrays.
  • Small syntax slips rarely lose points; missing logic and unattempted parts do.

How is the AP CSA free-response section structured?

College Board's AP Computer Science A exam page sets out the format: two sections of 1 hour 30 minutes each. Section I is 42 multiple-choice questions worth 55%. Section II is 4 free-response questions worth 45%, in which you write Java code. The 2027 exam is on 12 May 2027.

QuestionFocusTypical points
1Methods and control structures: loops, conditions, calling methods7
2Class design: write a complete class from a description7
3Data analysis with ArrayList: traverse, filter, add or remove5
42D arrays: nested loops over rows and columns6

That gives about 22 minutes per question. The point values are the ones used in our AP Computer Science score calculator, which converts your practice scores into an estimated 1 to 5. The course itself is organised into four units of Java, as the course overview shows.

How do graders award points?

Each question has a scoring guideline that lists separate points, such as 'loops over all elements', 'calls the helper method correctly', 'compares values', 'returns the correct result'. You earn each point independently. If your loop is right but your return value is wrong, you still earn the loop point.

This changes how you should work. Write the structure first: the method header is given, so add the loop, the condition and the return. Even if you cannot finish the middle, those pieces score. A blank answer scores zero; a half-right answer often scores half.

How do you approach each question type?

  • Question 1, methods and control structures. Part (a) and part (b) are often linked. If part (b) says to use the method from part (a), call it. Do not rewrite it, and assume it works even if your part (a) was wrong.
  • Question 2, class design. Write private instance variables, a constructor that sets them, and each method named in the description. Match the method names, parameters and return types exactly as the examples show.
  • Question 3, ArrayList. Use size(), get(), set(), add() and remove(). When removing while looping, go backwards or adjust the index, or you will skip elements.
  • Question 4, 2D arrays. Use arr.length for rows and arr[0].length for columns. Decide before you write whether you are going row by row or column by column.
for (int r = 0; r < grid.length; r++) {
    for (int c = 0; c < grid[0].length; c++) {
        if (grid[r][c] > max) {
            max = grid[r][c];
        }
    }
}

That nested loop pattern, with small changes, answers a large share of 2D array questions. Know it well enough to write it in under a minute.

What loses points?

  • Not attempting a part. The biggest loss of all. Always write something.
  • Ignoring given methods. If the question provides a method, graders expect you to use it.
  • Printing instead of returning. If the method has a return type, System.out.println does not earn the return point.
  • Changing data you were told not to change, such as modifying a parameter array when the question says it must stay the same.
  • Array and list confusion. Using length on an ArrayList or size() on an array, or square brackets on an ArrayList.
  • Off-by-one errors in loop bounds, especially <= where < is needed.

Minor slips, such as a missing semicolon where your meaning is obvious, are usually not penalised. Do not waste time recopying an answer to make it neat. Cross out clearly and move on.

How should you practise FRQs?

  1. Download past free-response questions and scoring guidelines from College Board's exam page.
  2. Write answers by hand, on paper, with a 22-minute timer per question. Typing in an editor hides the mistakes you will make in the exam.
  3. Mark your answer against the scoring guideline, point by point, and record which points you missed.
  4. Type your handwritten answer into a real compiler afterwards to see what would have failed.
  5. Redo the same question a week later without looking at your first attempt.

Start timed practice at least eight weeks before the exam, with two questions a week, rising to a full section in the final fortnight. A dated plan keeps this on track; see how to use AI to make a study plan.

What score do you need?

AP exams are scored from 1 to 5, and many universities give credit or placement for a 3 or above, with selective ones asking for a 4 or 5. College Board publishes the share of students earning each score on its AP CSA score distributions page. The exact composite score needed for each grade changes slightly every year.

As a rough guide, students who earn about two thirds of the free-response points and a similar share of the multiple choice are usually in range for a 4. Use the calculator to test your own numbers. Frequently asked questions

How many FRQs are on the AP Computer Science A exam?

Four. You have 1 hour 30 minutes for the free-response section, which is worth 45% of your exam score.

Do you lose points for syntax errors on AP CSA FRQs?

Small slips where your intent is clear, such as a missing semicolon, are usually not penalised. Missing logic, wrong method calls and unattempted parts lose points.

Can you get partial credit on AP CSA free response?

Yes. Each question is scored point by point, so correct loops, conditions and method calls earn credit even if the whole solution is not complete.
