AI-900 Is Retired: What the New AI-901 Exam Means for Beginners

By Syed Shahmikh Ali · Published 4 November 2026 · Updated 4 November 2026

You can no longer take Microsoft's AI-900 exam: Microsoft retired it on June 30, 2026 and replaced it with AI-901, which now earns the same Microsoft Certified: Azure AI Fundamentals certification. The big change is that AI-901 is no longer a "what is AI" exam for anyone. Microsoft now expects basic Python and spends more than half the exam on building small AI apps with Microsoft Foundry. If you already passed AI-900, you do not need to do anything.

Key takeaways

  • AI-900 was retired on June 30, 2026. AI-901 is the exam that now earns Microsoft Certified: Azure AI Fundamentals.
  • Microsoft lists basic Python syntax and programming concepts as expected knowledge for AI-901. AI-900 needed no coding.
  • Implementing AI solutions with Microsoft Foundry is 55 to 60% of AI-901, so hands-on practice matters more than flashcards.
  • If you already hold Azure AI Fundamentals from AI-900, Microsoft says no action is required, and fundamentals certifications do not expire.
  • Many 2026 "best AI certification" lists still recommend AI-900. Check the exam code before you buy any course or practice test.

What happened to the AI-900 exam?

Microsoft retired it. In its April 15, 2026 announcement, Microsoft said Exam AI-901 replaces Exam AI-900, which was being retired on June 30, 2026. That date has passed, so AI-901 is now the exam you book.

The certification name stays the same: Microsoft Certified: Azure AI Fundamentals. Only the exam behind it changed. That is why so many people get confused. They search for the certification, land on an older article or video that teaches AI-900, and do not notice the exam code.

Quick check before you pay for any course, book or practice test: it should say AI-901 and match Microsoft's skills list dated April 15, 2026. Material written only for AI-900 will miss most of the new exam.

What is different about AI-901?

AI-901 moves from describing AI to building with it. Microsoft's own comparison table in the announcement sums it up like this:

AreaAI-900 (retired)AI-901 (current)
AudienceNontechnical or technical beginnersTechnical beginners planning to build AI solutions
Focus"What is AI?""How do I build an AI app by using Foundry?"
Python neededNoneBasic Python syntax and programming concepts

The official AI-901 study guide splits the exam into two parts:

  • Identify AI concepts and capabilities (40 to 45%): responsible AI principles, how generative AI models work, choosing and configuring models, and common workloads such as text analysis, speech, computer vision and information extraction.
  • Implement AI solutions by using Microsoft Foundry (55 to 60%): writing system and user prompts, deploying a model in the Foundry portal, building a lightweight chat client with the Foundry SDK, creating and testing a single agent, and building small apps for text, speech, vision and document extraction.

The study guide also says you should be familiar with REST APIs, SDKs and CLIs, and that you need a score of 700 or more to pass.

Do you need to know Python for AI-901?

Yes, at a basic level. The study guide's audience profile says you need "knowledge of Python coding syntax and programming techniques" and should be familiar with Azure resources. You do not need to be a developer, but you should be able to read a short Python script and understand what it does.

In practice, basic means you are comfortable with:

  • variables, strings, lists and dictionaries
  • if statements and loops
  • calling a function and reading what it returns
  • installing a package and running a script from the terminal

This is my teaching view rather than a Microsoft definition, but it matches what the Foundry tasks in the study guide involve: small client apps that send a prompt and handle the response. If none of that list is familiar, spend two to four weeks on Python first. It will make AI-901 far easier, and the Python is useful on its own.

Is an AI-900 certification still valid?

Yes. Microsoft's announcement says that if you already hold the certification, no action is required, and that taking AI-901 will not change the name of your existing credential. Microsoft's credential expiration policy also states that fundamentals certifications do not expire.

So there is no need to retake anything. Taking AI-901 anyway only makes sense if you want the hands-on Foundry skills it covers, not to keep your certification alive.

How much does AI-901 cost, and is it free?

The exam is paid. The Azure AI Fundamentals certification page says the price is based on the country or region where the exam is proctored, and does not include taxes, so you see your real price when you schedule.

The preparation can be free. The study guide points to a free Practice Assessment on Microsoft's AI Skills Navigator (you need to sign in) and an exam sandbox where you can try the exam interface before test day.

One thing to watch: discount offers do not always apply everywhere. The AI-901 beta discount in Microsoft's announcement, for example, was limited to the first 300 people and was not available in Turkey, Pakistan, India or China. Always read the country rules on an offer before you plan around it.

Who should take AI-901 now?

AI-901 is a good fit if you want to build with AI, not just talk about it. Here is how I would decide, based on where you are starting from.

Your situationWhat to do
You can write basic Python and want a Microsoft AI certificationTake AI-901. Practice in the Foundry portal, not just with notes.
You have never codedLearn basic Python first, then AI-901. For a quick no-code start, a free beginner AI badge is a better first step.
You already passed AI-900Nothing required. Take AI-901 only if you want the hands-on skills.
You are halfway through an AI-900 courseKeep the concept parts, then switch to the AI-901 study guide for the Foundry half.

A 4-week plan if you already know basic Python

This is my suggested plan, not an official Microsoft schedule. Adjust it to your pace.

  1. Week 1: Read the study guide line by line. Cover responsible AI and the AI workloads part of domain 1.
  2. Week 2: In Foundry, deploy a model, write system and user prompts, and build a small chat client with the SDK.
  3. Week 3: Build one small app each for text analysis, speech and vision, then try information extraction from a document.
  4. Week 4: Take the free Practice Assessment, review weak areas against the study guide, and try the exam sandbox before you book.

Frequently asked questions

Can I still book the AI-900 exam?

No. Microsoft retired AI-900 on June 30, 2026. AI-901 is now the exam that earns Microsoft Certified: Azure AI Fundamentals, so book that instead.

Is AI-901 harder than AI-900?

For people who cannot code, yes. AI-900 needed no coding, while Microsoft lists basic Python as expected knowledge for AI-901 and gives 55 to 60% of the exam to building solutions in Microsoft Foundry. If you can already write simple Python, the jump is manageable with hands-on practice.

Does the Azure AI Fundamentals certification expire?

No. Microsoft's credential expiration policy says fundamentals certifications do not expire. Role-based associate and expert certifications are the ones that need yearly renewal.
